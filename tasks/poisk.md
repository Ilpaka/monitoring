# Поиск сайтов и фильтр сбоев

Добавить над карточками поиск по названию и флажок «Только неработающие». Поиск игнорирует регистр и пробелы по краям. Сводка по группе сохраняет значение при любом фильтре.

## Готово, когда

- Поиск по части названия оставляет подходящие карточки.
- При включённом флажке видны только сайты с последней неудачной проверкой. Сайт без замера имеет отдельное состояние.
- Условия работают вместе. При пустом результате появляется «Сайтов не найдено».
- Поля имеют названия и доступны с клавиатуры. Автоматические проверки проходят.
