# Правила мониторинга

Проект использует React, TypeScript и Vite. Данные всех страниц загружает MonitoringProvider. Сводка учитывает весь список сайтов. При фильтрации отсутствие замера означает «Нет проверки».

Перед сдачей запустите `npm test`, `npm run lint` и `npm run build`. Проверьте поиск и смену страницы с клавиатуры. В журнале запишите, какую правку приняли, какую отклонили и какая проверка помогла это решить.
